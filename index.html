부동산 자산 디지털 플랫폼 (real8)

홈 · 회원가입 · 로그인 · 자산 안내

이 페이지는 실제 서비스 개발 전에 구조와 흐름을 검증하기 위한 로컬 연습용 데모입니다.
(회원 정보와 토큰 기록은 이 컴퓨터의 브라우저 localStorage에만 저장됩니다.)

사이트 구성 및 각 페이지 사용 설명

  • 블록체인·토큰코인 관리(관리자) : 부동산 정보 등록/검증, 토큰 증감(%), 코인 변환율(%), 회원 각 거래 시 배율을 설정합니다.
  • 건축·매매·임대·바꿔살기(정보 등록) : 회원들이 실제 부동산 정보(주소, 면적, 사진 등)를 등록하고, 검토 후 승인이 되면 토큰이 자산으로 적립됩니다.
  • 가상 건축 제안·참여 : 가상의 부동산 프로젝트(리모델링, 개발 등)를 제안/참여할 수 있으며, 참여도에 따라 토큰 보상이 이루어집니다.
  • 마이페이지 : 회원별 누적 토큰/코인, 참여 이력, 등록한 부동산 목록을 조회할 수 있습니다. (현재는 기본 정보만 표시)
  • 광고·홍보 계정 : 부동산 중개업소·시행사·시공사 등의 광고와 PR를 위한 공간입니다. 일정 토큰/코인을 사용해 광고를 노출할 수 있습니다.
  • 보관 방식 : 실제 서비스에서는 별도 서버·DB·블록체인을 사용하지만, 이 데모는 localStorage에만 저장됩니다.

아래 기준은 사업 설명용 예시이며, 실제 비율은 추후 투자자·참여자와 협의하여 조정할 수 있습니다.

토큰 보상 기준표 (예시)

구분 행동 지급 토큰
부동산 정보 주소·면적·사진·거래 정보 등 정보 등록 200 Token
개발/개선 제안 리모델링, 용도 변경 등 프로젝트 제안 100 Token
가상 건축 참여 댓글·투표·아이디어 제공 등 참여(의견 제시) 20 Token
주거경험 공유 거주 후기·유지보수 경험 등 정보 공유(글) 50 Token
커뮤니티 활동 다른 회원 글에 댓글·질문·답변 등 소통 20 Token

현재 환산율 예시: 100 Token = 1 Coin (실제 비율은 추후 조정)

새 토큰 기록 추가 (해시값 생성 데모)

부동산 주소 + 사이트 주소 + 발행 시간 텍스트를 합쳐서 SHA-256 해시값을 생성합니다. 이 해시값은 나중에 블록체인에 기록할 수 있는 기본 데이터가 됩니다.

※ 해시 생성은 브라우저에서만 이루어지며, 실제 코인 발행·입출금 기능은 포함되어 있지 않습니다.

전체 코인 발행 대장 (로컬 저장)

시간 소유자 부동산 주소 토큰 수량 해시값 (Proof)

※ 이 표의 내용은 브라우저 localStorage에 저장되며, 이 컴퓨터·이 브라우저에서만 보입니다.

건축·매매·임대·바꿔살기 (정보 등록)

이 영역에는 향후 실제 부동산 등록 양식(주소, 면적, 구조, 사진 업로드 등)을 넣을 예정입니다.
지금은 전체 구조만 잡아둔 상태입니다.
